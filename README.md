# Missione Logistica

Gioco di orientamento dell'ITE Martino Filetico di Ferentino per il diploma in 4 anni, curvatura Logistica.

Tre missioni: il mezzo giusto, il giro delle consegne, le scorte. Web app installabile, funziona anche offline.

Date degli open day e link si modificano nel blocco `CONFIG` all'inizio di `index.html`.
